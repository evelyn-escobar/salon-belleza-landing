# Salón Bella Estilo – Landing page

Landing page responsive para un salón de belleza, desarrollada con HTML, CSS y JavaScript, sin librerías externas.

**Ver en vivo:** https://evelyn-escobar.github.io/salon-belleza-landing/

## Funcionalidades

- Diseño responsive: se adapta a celular, tablet y computador.
- Menú de navegación fijo, con menú desplegable en celulares.
- Sección de servicios en tarjetas con CSS Grid.
- Horario de atención con un indicador que muestra si el salón está abierto en ese momento (JavaScript).
- Botón de WhatsApp con mensaje predeterminado para agendar citas, más un botón flotante.
- Desplazamiento suave entre secciones y año automático en el pie de página.

## Tecnologías utilizadas

- HTML5 semántico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3: variables, Flexbox, Grid, media queries y transiciones
- JavaScript (DOM y eventos)
- GitHub Pages para la publicación

## Cómo verlo en tu computador

```bash
git clone https://github.com/evelyn-escobar/salon-belleza-landing.git
cd salon-belleza-landing
```

Luego abre `index.html` en el navegador.
